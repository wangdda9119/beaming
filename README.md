## 🔍 프로젝트 개요

**Beaming**은 사용자가 입력한 검색어에 대한 **뉴스 제목과 요약문**을 기반으로,  
해당 이슈에 대한 대중 정서를 **긍정/부정 감성 비율로 분석**하는 AI 웹 서비스입니다.

이 프로젝트는 단순히 오픈모델을 적용하는 수준을 넘어서,  
**데이터 수집 → 모델 파인튜닝 → 서비스 구현까지 End-to-End 전체를 직접 구축**한 실전 프로젝트입니다.

---

## 🚨 문제의식

> 📌 **기존 감정분석 모델은 뉴스 데이터에 적합하지 않았다**

- 네이버 News API는 오직 **제목, 요약, 기사 링크만 제공**  
- 즉, 전체 본문이 없기에 **제목 + 요약문만으로 감정을 파악해야 함**
- 공개된 한국어 감정 분석 모델("sentiment-analysis","monologg/koelectra-base-finetuned-nsmc")을 테스트한 결과  
  → **정확도 약 50% 내외로 실사용에 부적합**

---



## 🔧 해결 전략

> 🎯 **나만의 도메인 전용 감정 분석 모델을 구축**

1. 다양한 뉴스 도메인(정치, 경제, 사회 등)에 대해 **데이터 4만개 수집**
2. "monologg/koelectra-base-finetuned-nsmc"모델의 추론에서 긍정은 확신도 95%, 부정은 확신도 80% 이상이 되는 데이터만을 선별 → **신뢰 높은 라벨링 데이터셋 생성**
3. 한국어에서 성능이 뛰어난 **RoBERTa 기반 사전학습 모델**을 선택
4. HuggingFace 기반 **파인튜닝 진행** (`transformers` + `PyTorch`)
5. 최종적으로 **검증 정확도 98.18% 달성**

## ⚖️ 데이터 불균형 처리 전략
학습 데이터는 긍정:부정 비율이 약 9:1로 심각하게 불균형한 상태였습니다.

이를 해결하기 위해 다음과 같은 비율 반영 기반 학습 전략을 적용했습니다:

!! 클래스 가중치(Class Weighting)
→ 손실 함수(CrossEntropyLoss)에 클래스별 가중치를 반영해,
소수 클래스인 '부정' 라벨이 무시되지 않도록 보정

!! 데이터 검증 시, 비율 유지
→ 학습셋/검증셋 분할 시 원래의 9:1 비율을 그대로 유지해
실제 배포 환경과 일치하는 평가 구조를 유지

!! Threshold 조정
→ 추론 시 label_1(긍정)은 신뢰도 0.95 이상,
label_0(부정)은 0.8 이상일 경우에만 출력하도록
감정 분류의 신뢰도 기준을 클래스별로 다르게 설정

## 🧠 기술 스택

| 범주 | 사용 기술 |
|------|-----------|
| 데이터 수집 | Naver News API |
| 모델링 | Ko-RoBERTa + Transformers |
| 학습 프레임워크 | PyTorch |
| 웹 프레임워크 | Flask |
| 전처리 | 맞춤형 요약+토큰화 파이프라인 |
| 배포 | 로컬/클라우드 추론 서버 |

---

## 🖥️ 주요 기능

- 사용자가 입력한 키워드 기반 뉴스 수집
- 제목 + 요약문 감정 분석 (긍정/부정 비율 시각화)
- 시각적인 결과 HTML 렌더링
